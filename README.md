### About the Experiment 

This experiment presents an interactive simulation of the Euclidean Distance concept, demonstrating how the distance between two points is calculated in a coordinate space through step-by-step visualization. It allows users to input coordinates (in 2D or multi-dimensional space) or generate random coordinates, observe the computation process, and understand how the distance is derived using the mathematical formula. The simulation provides visualization of both the geometric representation and the recursion tree, followed by detailed step logs of the computation. Additionally, it includes runtime metrics to analyze performance and offers a comparison between brute force and divide and conquer approaches for large input sizes, helping learners understand efficiency and scalability.
